## Featured projects

### 🪒 [Barbershop Booking Scheduler](https://github.com/Ristathebest/barbershop-scheduler)
Full booking system for a barbershop — client-facing booking flow with live slot availability, an admin dashboard for managing services/staff/hours, JWT-protected admin auth, and automated confirmation + reminder emails.
**Live:** [barbershop-scheduler-orpin.vercel.app](https://barbershop-scheduler-orpin.vercel.app/)

### 📰 [The Signal — Personalized News](https://github.com/Ristathebest/web-app-news)
A news reader with a feed tailored to your interests — technology, business, sports, science, health, entertainment, and more. Browse headlines, save articles, and switch between light/dark mode. React 19 frontend (Tailwind CSS, shadcn/ui) backed by a Python FastAPI service that proxies a live news API.
**Live:** [web-app-news.vercel.app](https://web-app-news.vercel.app/)

### 🔒 [Vault](https://github.com/Ristathebest/Vault)
A mobile app for securely storing sensitive personal information — passwords, card details, PINs, IDs, documents, and photos — entirely offline, with no account or server required. Data is encrypted and stored locally on-device, unlocked via PIN or biometrics. Vaults can be exported as a passphrase-encrypted file and re-imported later. Built with React Native (Expo Router, TypeScript).
