## Featured projects

### Membership & Payments Platform
Internship project for a client, built by a team of four that I led. Online registration with Square card payments checked on the server, emailed receipts with QR codes, QR check-in, attendance reports, and an admin dashboard with staff and admin roles. Includes a vaccination certificate checker that runs as a scheduled background job. Built with Next.js, Supabase, Square and Resend. [Live demo](https://esdtc-app.vercel.app)

### Barbershop Booking Scheduler
Full booking system for a barbershop: client-facing booking flow with live slot availability, an admin dashboard for managing services, staff and hours, JWT-protected admin auth, and automated confirmation and reminder emails. [Live demo](https://barbershop-scheduler-orpin.vercel.app) · [Code](https://github.com/Ristathebest/barbershop-scheduler)

### The Signal: Personalized News
A news reader with a feed tailored to your interests across technology, business, sports, science, health and entertainment. Browse headlines, save articles, and switch between light and dark mode. React 19 frontend (Tailwind CSS, shadcn/ui) with a Python FastAPI service that proxies a live news API. [Live demo](https://web-app-news.vercel.app) · [Code](https://github.com/Ristathebest/Web-app-News)

### Vault
A mobile app for securely storing sensitive personal information (passwords, card details, PINs, IDs, documents and photos) entirely offline, with no account or server. Data is encrypted and stored locally, unlocked with a PIN or biometrics, and can be exported as a passphrase-encrypted file. Built with React Native (Expo Router, TypeScript). [Code](https://github.com/Ristathebest/Vault)
